# The Meridian Post

A hand-drawn newspaper image for Thursday 26 November 2026, with a navy lead band and an asymmetric three-column news layout. Python's standard library powers the original bitmap alphabet, canvas and PNG encoder. `main.py` copies the included `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`, or renders the same image if the included PNG is absent.
